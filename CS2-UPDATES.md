# CS2 в VladLoader 0.1.8

16.11.2026: исправлен запуск. Вместо обработки `steam://` используется
установленный `steam.exe -applaunch 730 -allow_third_party_software -dx11`.
Перед подключением нужны готовые модули, отвечающее окно и стабильный PID.
Проверка кода завершения больше не принимает пустой ExitCode за успех;
после загрузчика проверяются наличие DLL и работа окна игры. До завершения
проверки статус «CS2 работает» не показывается. Лаунчер отслеживает закрытие
игры и разблокирует повторный запуск.

Нативная проверка на ПК владельца прошла: Steam/CS2 запущены новой функцией,
стандартный UAC подтверждён пользователем, DLL загружена, игра отвечает,
журнал Nexus подтверждает продолжающуюся отрисовку более минуты. В исходном
сбое журнал Steam показывал отсутствие параметра разрешения модулей,
а Nexus сообщал об отказе загрузки. Пройдено 25 тестов и изолированная
проверка интерфейса с отказом, повторной попыткой и закрытием игры.

Исходные готовые файлы найдены в `E:\Nexus\build-local\Release`.
Лаунчер устанавливает только `nexus_loader.exe` и `nexus_menu.dll`.
Отдельный `nexus_menu.exe` с демонстрационным окном не используется.

Кнопка запуска проверяет серверный доступ CS2 и целостность компонентов,
открывает CS2 через Steam, ждёт процесс до трёх минут и запускает существующий
загрузчик с `--no-pause --no-launch --pid <PID>` без его меню. Запрос UAC остаётся
видимым пользователю. Используется штатный параметр Steam
`-allow_third_party_software`, который уже используется загрузчиком Nexus.
Защита Windows и античит не изменяются.

## Как обновлять

В репозитории https://github.com/pitorito234-glitch/VladLoader создайте новый
обычный, не предварительный релиз с уникальным тегом, например `cs2-0.1.1`.
До публикации прикрепите оба файла с точными именами:

- `nexus_loader.exe`
- `nexus_menu.dll`

Затем опубликуйте релиз. GitHub вычисляет SHA-256 каждого вложения. Лаунчер
выбирает самый свежий опубликованный релиз `cs2-*`, получает размеры и хеши
через GitHub API и предлагает «Обновить». Нажмите проверку обновлений или
откройте CS2 заново. Пересобирать сам VladLoader для смены DLL не нужно.
Манифест вручную писать не требуется. Не заменяйте файлы уже опубликованной
версии: для обновления всегда используйте новый тег.

На этом компьютере доступна и команда публикации:

```powershell
& E:\VladLoader\scripts\publish-cs2.ps1 -Version 0.1.1
```

GitHub CLI должен быть авторизован. Пароли и секретные ключи в файлы проекта
не добавляются. Публичный репозиторий раздаёт файлы публично; проверки доступа
в лаунчере не делают вложения релиза приватными.

## Проверка

Модульные проверки покрывают выбор релиза, состав и хеши компонентов,
перенаправления GitHub, передачу путей без подстановки в команду, ошибки UAC,
ограниченное ожидание CS2 и существующие лицензии/сессии/установщик файлов.
После замены DLL или обновления CS2 нативную проверку подключения нужно
повторять: успешные модульные тесты не подтверждают совместимость новой DLL
с изменившейся игрой.
